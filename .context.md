Infinite OS Marketplace repository containing installation manifests for applications, frameworks, and stacks supported by Infinite OS. Each catalog item includes a manifest file (JSON or YAML) defining installation steps, dependencies, and metadata, plus an assets directory with images and configuration files.

## Summary

- README.md — Project documentation including manifest schema properties and system data fields
- CHANGELOG.md — Version history and changes
- CONTRIBUTING.md — Contribution guidelines
- LICENSE.md — Project license
- .gitignore — Git ignore patterns
- app/ — Application manifests (WordPress, Drupal, n8n, etc.)
- framework/ — Framework manifests (Laravel, etc.)
- stack/ — Stack manifests (LAMP, etc.)
- .agents/ — Agent configuration and skills (git-ignored)
- .memory/ — Memory storage for agents (git-ignored)
- .vscode/ — VS Code settings

## Constraints

- Manifest files MUST use either JSON (`.json`) or YAML (`.yml`, `.yaml`) format.
- Each catalog item MUST include an `avatarUrl` property pointing to a valid image.
- The `type` property MUST be one of: `app`, `framework`, or `stack`.

## Guidance

- Application manifests SHOULD include `installCmdSteps` and `uninstallCmdSteps` for complete lifecycle management.
- Assets directories SHOULD contain `avatar.jpg` or `avatar.png` (720x720 pixels recommended) and optional screenshots.
