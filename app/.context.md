Application manifests directory containing 18 catalog items that can be installed via Infinite OS. Each subdirectory represents a deployable application with installation instructions, dependencies, and branding assets.

## Summary

- adminer/ — Lightweight database management tool (PHP-based)
- adobeCommerce/ — Adobe Commerce (e-commerce platform)
- drupal/ — Open source CMS platform
- evolution-api/ — WhatsApp automation API
- joomla/ — Content management system
- mautic/ — Marketing automation platform
- moodle/ — Learning management system
- n8n/ — Workflow automation platform
- opencart/ — Open source e-commerce platform
- openmage/ — Magento fork (e-commerce)
- passbolt/ — Open source password manager
- phpmyadmin/ — MySQL/MariaDB web administration tool
- privatebin/ — Zero-knowledge paste bin
- supabase/ — Open source Firebase alternative
- typebot/ — Chatbot builder
- umami/ — Privacy-focused web analytics
- uptime-kuma/ — Self-hosted monitoring tool
- wordpress/ — WordPress — Web content management system

## Constraints

- Each application subdirectory MUST contain a manifest file (`.json`, `.yml`, or `.yaml`).
- Each application subdirectory MUST contain an `assets/` directory with at minimum an avatar image.
- Manifest `type` property MUST be set to `app`.

## Guidance

- Application manifests SHOULD specify required services in the `services` property (e.g., `php:8.2`, `mariadb`).
- Applications requiring user configuration SHOULD define `dataFields` for installation-time parameters.
