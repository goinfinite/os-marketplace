Adminer application manifest — a lightweight database management tool written in PHP. Provides a simple web interface for managing MySQL, PostgreSQL, SQLite, and other databases.

## Summary

- manifest.yml — Application manifest defining installation steps, dependencies (PHP), and metadata
- assets/ — Avatar and five UI screenshots for marketplace display

## Constraints

- Installation downloads Adminer v5.3.0 from GitHub releases.
- PostgreSQL support requires additional configuration of pg_hba.conf if detected.

## Guidance

- The install script checks for PostgreSQL installation and will edit pg_hba.conf (overwriting or appending authentication rules as applicable) and will restart the PostgreSQL and PHP services automatically. Caution is advised for shared/production environments; back up pg_hba.conf beforehand.
