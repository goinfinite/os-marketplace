Adobe Commerce application manifest — an enterprise e-commerce platform (formerly Magento Commerce) for building multi-channel B2B and B2C commerce experiences.

## Summary

- manifest.yml — Application manifest defining Composer-based installation from repo.magento.com, OpenSearch configuration, and `bin/magento setup:install`
- assets/ — Directory containing avatar and screenshots

## Constraints

- Requires `php:8.2`, `mariadb:10.6`, and `opensearch` services.
- Admin password MUST be at least 16 characters (enforced by install script).
- Requires Adobe Commerce repository public/private keys as data fields; the global Composer credential is cleared after install.
- Protects `app/etc` with a 403 mapping.

## Guidance

- The manifest description requires at least 2GB of RAM; installation is heavy and long.
