## Summary

- manifest.json — Application manifest with Composer-based installation, Drush site setup, and database configuration
- assets/ — Directory containing avatar and screenshots
  - avatar.jpg — Application icon (720x720)
  - screenshot-1.jpg through screenshot-4.jpg — UI screenshots for marketplace display

## Constraints

- Requires PHP 8.3 and MariaDB 10.6 services.
- Installation uses Composer to create project and Drush for site installation.
- Creates database and database user during installation.

## Guidance

- The install script creates the project in `/app/drupal-{hostname}-{uuid}/` and symlinks the web directory.
- File ownership is set to `nobody:nogroup` for proper web server access.
