Evolution API application manifest — an open-source WhatsApp integration API supporting multiple messaging services. Provides a RESTful API for WhatsApp Web control using the Baileys library.

## Summary

- manifest.yml — Application manifest defining Node.js-based installation with PostgreSQL and Redis dependencies
- assets/ — Directory containing avatar, screenshots, and environment configuration
  - avatar.jpg — Application icon (720x720)
  - env.txt — Environment configuration template
  - screenshot-1.jpg through screenshot-3.jpg — UI screenshots for marketplace display

## Constraints

- Requires PostgreSQL 15 and Redis 7.2 services.
- Clones from GitHub repository (version 2.3.7) during installation.
- Generates a random API key during installation using OpenSSL.

## Guidance

- Uses `mise` to manage Node.js version 24.
- Creates a Node.js service using `os services create-installable` after setup.
