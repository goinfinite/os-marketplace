Marketplace images and the environment template for Evolution API. The manifest copies `env.txt` into the install as `.env` and replaces its placeholders.

## Summary

- avatar.png — Application icon (720x720)
- env.txt — Environment template; placeholders `server_url`, `pg_user`, `pg_pass`, `pg_db`, `evolution_api_key` are substituted at install
- screenshot-0.png through screenshot-3.png — UI screenshots for marketplace display

## Constraints

- Image file paths MUST match the `avatarUrl` and `screenshotUrls` in ../manifest.yml.
