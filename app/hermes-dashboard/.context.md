Hermes Dashboard application manifest — the web dashboard companion for the Hermes agent. It registers a second service that reuses the installed agent.

## Summary

- manifest.yaml — Application manifest defining a custom service built on the installed hermes-agent
- assets/ — Avatar image and the dashboard startup script

## Constraints

- Declares `hermes-agent` in the `services` property; the install aborts if the agent is not already installed.
- Runs as a custom service on port 9119/http with auto-start and auto-restart disabled.
- The service version is read from the installed hermes-agent service.

## Guidance

- The install copies `assets/start_hermes_dashboard.sh` to `/app/hermes-agent/` and uses it as the start command.
- Uninstallation deletes the service by name and port match via jq.
