Joomla application manifest — a free and open-source content management system (CMS) for publishing web content. Built on a model-view-controller web application framework.

## Summary

- manifest.json — Application manifest with CLI-based installation using Joomla's built-in installer
- assets/ — Directory containing avatar and screenshots
  - avatar.jpg — Application icon (720x720)
  - screenshot-1.jpg through screenshot-3.jpg — UI screenshots for marketplace display

## Constraints

- Requires PHP 8.2 and MariaDB services.
- Admin password MUST be at least 12 characters (enforced by install script).
- Uses Joomla CLI installer (`installation/joomla.php install`) for automated setup.

## Guidance

- Installation downloads a pre-packaged Joomla zip from goinfinite.net assets.
- Database and user are created with system-generated credentials.
