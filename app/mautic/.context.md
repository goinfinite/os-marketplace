Mautic application manifest — an open-source marketing automation platform for managing marketing campaigns, tracking customer interactions, and automating marketing tasks.

## Summary

- manifest.yml — Application manifest defining PHP-based installation with admin user configuration and scheduled jobs
- assets/ — Directory containing avatar and screenshots

## Constraints

- Requires PHP and MariaDB services; the install updates the PHP runtime to 8.3.
- The OS PHP runtime cannot enable the imap extension. Composer ignores the `ext-imap` platform requirement; Mautic treats imap as optional (only monitored email needs it).
- The CLI installer aborts (with exit 0) unless `var/cache` and `var/logs` exist in the project root; the install creates them before running `mautic:install`.
- Requires admin user configuration (username, password, first name, last name, email).
- Registers three cron jobs (segments update, campaigns update, campaigns trigger) and deletes them on uninstall.

## Guidance

- Installation runs the mautic:install command non-interactively with --no-interaction and --force flags; no web-based setup wizard required.
- The app lives in `/app/mautic_<hostname>` and the install directory is a symlink to its `docroot`.
