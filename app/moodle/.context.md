Moodle application manifest — an open-source online learning platform built in PHP for creating and managing virtual learning environments.

## Summary

- manifest.yml — Application manifest defining PHP-based installation with admin and site-name configuration
- assets/ — Directory containing avatar, screenshots, and an .htaccess file copied into the install

## Constraints

- Requires PHP 8.3 and MariaDB services (PHP 8.3 is the minimum for Moodle 5.2).
- Downloads a commit-pinned archive (commit 344232c15336c71b80f9aca8359ce0e0a9f3d116, what tag v5.2.3 resolves to) from the official GitHub mirror (`github.com/moodle/moodle`) and verifies its SHA-256 digest before extraction; a mismatch aborts the install. The old `download.moodle.org` URL 302-redirects to `packaging.moodle.org`, a Cloudflare host that serves a "Moodle challenge" 403 to datacenter IPs, breaking CI. A commit cannot be retargeted like a tag can.
- Fresh installs only receive Moodle security updates when a human bumps the pinned commit and its digest in the manifest. No bump automation exists in the repo.
- Moodle 5.x serves from the `public/` subdirectory; the install keeps the code in `/app/moodle_<uuid>` and symlinks the install directory to its `public/` dir. The GitHub archive extracts under a `moodle-<commit>/` prefix, so the tar step strips it into a `moodle/` dir.
- Requires admin user configuration (username, password, email) and site full/short names.
- Sets utf8mb4 collation on the database before install (avoids a charset mismatch).

## Guidance

- Installation runs Moodle's CLI installer (`admin/cli/install.php`) non-interactively; no web-based setup wizard is required.
- The `.htaccess` asset (routes everything through `r.php`) is copied into `public/`, not the code root.
- A `MoodleCron` job runs `admin/cli/cron.php` every minute; uninstall moves the code tree and data to `/app/.trash/` and removes the symlink.
- Uninstall tolerates both layouts: the current one with the code in `/app/moodle_<uuid>`, and the legacy 4.5 one with the files inside the install directory.
- Moodle data lives in `/app/<hostname>-moodledata`, outside the install directory.
