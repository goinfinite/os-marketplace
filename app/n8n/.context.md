## Summary

- manifest.yml — Application manifest defining Node.js-based installation and service creation
- assets/ — Directory containing avatar, screenshots, and environment configuration
  - avatar.jpg — Application icon (720x720)
  - env.txt — Environment configuration template for n8n
  - screenshot-1.jpg through screenshot-3.jpg — UI screenshots for marketplace display

## Constraints

- Does not use the `services` property; instead creates the Node.js service during `installCmdSteps` using `os services create-installable`.
- Requires Node.js version 20.
- Installation timeout set to 900 seconds due to npm package installation time.

## Guidance

- The install script uses `mise` to manage Node.js versions.
- Uninstallation removes the service and moves n8n data to `/app/.trash/` with timestamp.
