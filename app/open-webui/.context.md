Open WebUI application manifest — a self-hosted, extensible web interface for LLM interactions with OpenAI-compatible APIs, local models via Ollama, multi-user management, and RAG.

## Summary

- manifest.yml — Application manifest defining a pip-based installation and a custom web service
- assets/ — Avatar image

## Constraints

- Installs the pinned version `open-webui==0.9.6` via `mise x python@3.11 -- pip install`.
- Runs as a custom service (`os services create-custom`) named `open-webui` on port 8080/ws.
- Installation timeout set to 600 seconds.

## Guidance

- Uninstallation removes the package with pip-autoremove, deletes the service by name, and purges pip, huggingface, chroma caches and `/infinite/.webui_secret_key`.
