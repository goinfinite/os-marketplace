OpenCart application manifest — an open-source e-commerce platform for online merchants. Provides a professional foundation for building a successful online store.

## Summary

- manifest.yml — Application manifest defining PHP-based installation via OpenCart's CLI installer
- assets/ — Directory containing avatar and screenshots

## Constraints

- Requires `php:8.2` and MariaDB services.
- Downloads a pre-packaged OpenCart zip from goinfinite.net assets.

## Guidance

- Installation runs `install/cli_install.php` non-interactively; no web-based setup wizard is required.
- Database and user are created with system-generated credentials.
