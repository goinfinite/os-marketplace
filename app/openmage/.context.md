OpenMage application manifest — a community-driven fork of Magento 1, the open-source e-commerce platform. Maintains compatibility while providing security updates and improvements.

## Summary

- manifest.json — Application manifest defining Composer-based installation and `install.php` setup
- assets/ — Avatar and three UI screenshots for marketplace display

## Constraints

- Requires `php:8.2` and MariaDB services.
- Composer minimum-stability is set to `dev` with prefer-stable to resolve OpenMage dependencies.
- Protects `app/etc` with a 403 mapping.

## Guidance

- Suitable for existing Magento 1 users seeking continued open-source support.
