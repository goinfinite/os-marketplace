Passbolt application manifest — an open-source credential platform for teams. Manages passwords, accesses, and secrets with GPG end-to-end encryption.

## Summary

- manifest.yml — Application manifest defining PHP-based installation with GPG key generation and JWT setup
- assets/ — Directory containing avatar, screenshots, the Passbolt config template, and a GPG key template

## Constraints

- Requires PHP (runtime updated to 8.3, ldap/pear/gnupg extensions) and MariaDB services.
- Requires admin name/email and full SMTP configuration as data fields.
- Generates server GPG keys as user `nobody` and JWT keys (`chmod 500` on the JWT config directory).
- Registers a `PassboltCron` email-queue job every minute; uninstall removes it and deletes the GPG keys.

## Guidance

- The install clones passbolt_api from GitHub and configures it by substituting placeholders in `assets/passbolt.default.php`.
