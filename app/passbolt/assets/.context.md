Marketplace images and configuration templates for Passbolt. The manifest copies both PHP/GPG templates during install and substitutes their placeholders.

## Summary

- avatar.jpg — Application icon (720x720)
- gpg-key-template.txt — GPG key generation template; name and email placeholders substituted at install
- passbolt.default.php — Passbolt config template copied to `config/passbolt.php`; hostname, datasource, SMTP, and GPG fingerprint placeholders substituted
- screenshot-0.webp and screenshot-1.png through screenshot-3.png — UI screenshots for marketplace display

## Constraints

- Image file paths MUST match the `avatarUrl` and `screenshotUrls` in ../manifest.yml.
