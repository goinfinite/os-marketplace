phpMyAdmin application manifest — a free and open-source administration tool for MySQL and MariaDB. Provides web-based database management interface.

## Summary

- manifest.yml — Application manifest defining Composer-based installation
- assets/ — Directory containing avatar and screenshots

## Constraints

- Requires PHP service.
- Installs via Composer (`composer create-project phpmyadmin/phpmyadmin`).
- Waits up to 60 seconds for the `php-webserver` service to be running before invoking Composer.
- Updates PHP runtime to version 8.3 after installation.

## Guidance

- Uses `os runtime php run` to execute Composer with proper permissions.
- Install directory is created and owned by `nobody:nogroup` before Composer runs.
