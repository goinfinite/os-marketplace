PocketBase application manifest — an open-source backend with an embedded SQLite database, built-in auth, REST API, and admin UI, delivered as a single Go binary.

## Summary

- manifest.yml — Application manifest defining binary download, custom service creation, and admin user setup
- assets/ — Directory containing the avatar image

## Constraints

- Downloads PocketBase v0.22.19 from GitHub releases and verifies the download with `sha256sum -c` against the release checksums.
- Requires `adminEmail` and `adminPassword` data fields.
- Runs as a custom service (`os services create-custom`) on port 8090/http; no `services` property is used.
- Uninstallation deletes the service by name/port match and removes `pocketbase`, `pb_data`, and bundled files via `uninstallFileNames`.

## Guidance

- The admin user is created with `pocketbase admin create` after a 5-second sleep so the service is up first.
