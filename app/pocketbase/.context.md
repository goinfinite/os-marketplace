# PocketBase Marketplace Manifest

## Overview

PocketBase is a lightweight backend solution that combines an embedded SQLite database with a built-in authentication system, REST API, and admin UI. It is designed for rapid prototyping and small-to-medium deployments.

## Application Details

- **Type**: Standalone App
- **Single Binary**: Yes (Go application)
- **Default Port**: 8090 (Admin UI)
- **Data Directory**: `./pb_data`

## Installation Process

### 1. Download and Setup
The installation script performs the following steps:
1. Installs `jq` for JSON processing
2. Downloads the PocketBase binary from GitHub releases (v0.22.19)
3. Extracts the binary to the installation directory
4. Makes the binary executable
5. Copies the environment template file

### 2. Service Creation
PocketBase runs as an installable service with the following configuration:
- **Startup Command**: `%installDirectory%/pocketbase_bin serve`
- **Port Binding**: 8090/tcp
- **Auto-start**: Enabled
- **Auto-restart**: Enabled
- **Environment Variables**:
  - `ADMIN_EMAIL`: Admin user email address
  - `ADMIN_PASSWORD`: Auto-generated secure password
  - `PB_DATA_DIR`: Data directory path

### 3. Configuration
Environment variables are configured via `env.txt` template:
- `ADMIN_EMAIL`: Admin account email
- `ADMIN_PASSWORD`: Admin account password (auto-generated)
- `PB_DATA_DIR`: Path to data directory

## Uninstallation Process

### 1. Service Removal
- Deletes the PocketBase service via `os services delete`

### 2. File Cleanup
- Removes the PocketBase binary
- Removes the `pb_data` directory containing all data
- Removes the `.env` file with configuration
- Removes `migrations` directory if present

### 3. Package Cleanup
- Removes the `jq` package installed during setup

## Data Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| adminEmail | text | Yes | Email address for PocketBase admin account |

## Placeholders

| Placeholder | Description |
|-------------|-------------|
| `%installDirectory%` | Installation directory path |
| `%installTempDir%` | Temporary directory for downloads |
| `%installRandomPassword%` | Auto-generated admin password |
| `%adminEmail%` | Admin email address from data field |
| `%marketplaceCatalogItemAssetsDirPath%` | Path to manifest assets |

## Security Notes

- Admin password is auto-generated using `%installRandomPassword%`
- No hardcoded credentials in manifest
- SQLite database stored locally in `pb_data` directory
- Data directory removed on uninstallation
