# PocketBase Marketplace Manifest

## Overview

PocketBase is a lightweight backend solution that combines an embedded SQLite database with a built-in authentication system, REST API, and admin UI. It is designed for rapid prototyping and small-to-medium deployments.

## Application Details

- **Type**: Standalone App
- **Single Binary**: Yes (Go application)
- **Default Port**: 8090 (Admin UI)
- **Data Directory**: `./pb_data`

## Installation Process

### 1. Download and Setup
The installation script performs the following steps:
1. Downloads the PocketBase binary from GitHub releases (v0.22.19)
2. Extracts the binary to the installation directory
3. Makes the binary executable

### 2. Service Creation
PocketBase runs as a custom service with the following configuration:
- **Startup Command**: `%installDirectory%/pocketbase serve`
- **Port Binding**: 8090/http
- **Auto-start**: Enabled
- **Auto-restart**: Enabled

### 3. Admin User Creation
After service starts, the admin user is created with the credentials provided via dataFields.

## Uninstallation Process

### 1. Service Removal
- Deletes the PocketBase service via `os services delete` (targets service by port 8090/http)

### 2. File Cleanup
- Removes the PocketBase binary
- Removes the `pb_data` directory containing all data
- Removes `migrations` directory if present

## Data Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| adminEmail | email | Yes | Email address for PocketBase admin account |
| adminPassword | password | Yes | Password for PocketBase admin account |

## Placeholders

| Placeholder | Description |
|-------------|-------------|
| `%installDirectory%` | Installation directory path |
| `%installTempDir%` | Temporary directory for downloads |
| `%installHostname%` | Installation hostname |
| `%adminEmail%` | Admin email address from data field |
| `%adminPassword%` | Admin password from data field |

## Security Notes

- Admin credentials are collected via dataFields during installation
- No hardcoded credentials in manifest
- SQLite database stored locally in `pb_data` directory
- Data directory removed on uninstallation
