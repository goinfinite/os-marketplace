PrivateBin application manifest — a minimalist, open-source online pastebin where the server has zero knowledge of pasted data. Uses encryption in the browser for privacy.

## Summary

- manifest.yml — Application manifest defining PHP-based installation from the PrivateBin 2.0.0 source tarball
- assets/ — Directory containing avatar, screenshots, and the PrivateBin configuration file

## Constraints

- Requires PHP service (runtime updated to 8.3).
- Zero-knowledge architecture — data encrypted client-side.
- Waits for `php-webserver` to reach RUNNING state via supervisorctl before updating the runtime.

## Guidance

- No database required; uses flat file storage by default.
- `assets/conf.php` is copied to `cfg/conf.php` with the hostname substituted.
