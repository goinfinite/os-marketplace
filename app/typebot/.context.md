Typebot application manifest — a powerful open-source chatbot builder for creating advanced conversational forms. Features 34+ building blocks including text, images, videos, conditional logic, webhooks, and OpenAI integration.

## Summary

- manifest.yml — Application manifest defining Node.js-based installation with PostgreSQL dependency and two custom services
- assets/ — Directory containing avatar, screenshots, environment and toolchain configs, and the builder/viewer startup scripts

## Constraints

- Requires PostgreSQL service.
- Requires admin email, builder subdomain, and SMTP configuration as data fields.
- Clones typebot.io v3.15.2 and builds with bun and turbo (monorepo, not docker-compose).
- Creates a subdomain vhost for the builder and two custom services: builder on port 3000/ws, viewer on port 3001/ws.

## Guidance

- The install substitutes placeholders in `assets/env.txt` and the SMTP password is escaped before sed.
- Uninstallation moves files to `/app/.trash/`, deletes both services, the vhost, and the database.
