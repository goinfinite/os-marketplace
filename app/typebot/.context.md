Typebot application manifest — a powerful open-source chatbot builder for creating advanced conversational forms. Features 34+ building blocks including text, images, videos, conditional logic, webhooks, and OpenAI integration.

## Summary

- manifest.yml — Application manifest defining Node.js-based installation with PostgreSQL dependency
- assets/ — Directory containing avatar, screenshots, and configuration files
  - avatar.jpg — Application icon (720x720)
  - env.txt — Environment configuration template
  - start_typebot.sh — Startup script for Typebot services
  - screenshot-1.jpg through screenshot-3.jpg — UI screenshots for marketplace display

## Constraints

- Requires PostgreSQL service.
- Requires admin email, builder subdomain, and SMTP configuration.
- Complex multi-service setup with builder and viewer components.

## Guidance

- Installation creates separate services for the builder and viewer interfaces.
- Uses `docker-compose` style deployment within the Infinite OS environment.
