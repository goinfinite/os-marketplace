Marketplace images, configuration templates, and startup scripts for Typebot. The manifest copies these files into the install and substitutes their placeholders.

## Summary

- avatar.png — Application icon (720x720)
- env.txt — Environment template; database, URL, admin email, SMTP, and encryption-secret placeholders substituted at install
- mise.toml — Toolchain version file copied into the repo checkout
- screenshot-0.png through screenshot-3.png — UI screenshots for marketplace display
- start_builder.sh — Startup script for the builder service (port 3000)
- start_viewer.sh — Startup script for the viewer service (port 3001)

## Constraints

- Image file paths MUST match the `avatarUrl` and `screenshotUrls` in ../manifest.yml.
- The startup scripts contain an `install_directory` placeholder replaced by sed before use.
