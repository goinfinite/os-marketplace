Umami application manifest — a self-hosted web analytics platform providing a user-friendly interface to monitor website traffic. Privacy-focused alternative to Google Analytics.

## Summary

- manifest.yml — Application manifest defining Node.js-based installation with PostgreSQL 16 dependency and a custom service
- assets/ — Directory containing avatar, screenshots, environment template, startup script, and a SQL privileges file

## Constraints

- Requires PostgreSQL 16 service.
- Generates a random 32-character app secret during installation using `openssl rand -hex 16`.
- Clones from the umami GitHub repository during installation.
- Runs as a custom service (`os services create-custom`) on port 3000/ws, started by `bash /app/start_umami.sh`.

## Guidance

- Installation configures database credentials and base path in the `.env` file and applies `assets/umami_user_privileges.sql` to the database.
- Builds with pnpm (`mise x pnpm@10.33 -- pnpm install && pnpm build`).
