<context path="app/umami/assets" updated="2026-09-17">

Marketplace images, configuration templates, startup script, and SQL privileges for Umami. The manifest copies these files during install and substitutes their placeholders.

## Summary

- avatar.png — Application icon (720x720)
- env.txt — Environment template; secret, database, and base-path placeholders substituted at install
- screenshot-0.png through screenshot-4.png — UI screenshots for marketplace display
- start_umami.sh — Startup script copied to `/app/`; the `install_dir` placeholder is replaced by sed
- umami_user_privileges.sql — SQL applied to the database; the `umami_user` name is replaced by sed

## Constraints

- Image file paths MUST match the `avatarUrl` and `screenshotUrls` in ../manifest.yml.
