Uptime Kuma application manifest — a self-hosted status monitoring solution with a user-friendly interface for monitoring service uptime. Supports various notification methods.

## Summary

- manifest.yml — Application manifest defining Node.js-based installation with SQLite database
- assets/ — Directory containing avatar and screenshots
  - avatar.jpg — Application icon (720x720)
  - screenshot-1.jpg through screenshot-3.jpg — UI screenshots for marketplace display

## Constraints

- Uses SQLite database (configured via `UPTIME_KUMA_DB_TYPE=sqlite` environment variable).
- Clones from GitHub repository during installation.
- Creates a Node.js service using `os services create-installable` on port 3001.

## Guidance

- Uses `mise` to manage Node.js version 20.
- Runs `npm run setup` to install dependencies and build the application.
- Uninstallation moves data to `/app/.trash/` with timestamp.
