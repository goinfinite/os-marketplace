Marketplace images and the .htaccess template for WordPress. The manifest copies `htaccess.txt` into the install as `.htaccess`.

## Summary

- avatar.jpg — Application icon (720x720)
- htaccess.txt — Apache rewrite rules copied as `.htaccess` at the end of install
- screenshot-1.jpg through screenshot-5.jpg — UI screenshots for marketplace display

## Constraints

- Image file paths MUST match the `avatarUrl` and `screenshotUrls` in ../manifest.json.
