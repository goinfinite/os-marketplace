Framework manifests directory containing structured software abstractions that provide tools and guidelines for development. Frameworks differ from applications in that they provide a foundation for building custom applications rather than being end-user ready.

## Summary

- laravel/ — Laravel PHP web application framework

## Constraints

- Each framework subdirectory MUST contain a manifest file (`.json`, `.yml`, or `.yaml`).
- Each framework subdirectory MUST contain an `assets/` directory with at minimum an avatar image.
- Manifest `type` property MUST be set to `framework`.

## Guidance

- Framework manifests SHOULD specify compatible PHP versions and database requirements.
- Frameworks typically require more complex installation steps including Composer dependencies.
