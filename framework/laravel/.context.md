Laravel framework manifest — a PHP web application framework with expressive, elegant syntax. Provides tools for routing, database abstraction, templating, and more.

## Summary

- manifest.yaml — Framework manifest defining installation via Composer, database setup, and environment configuration
- assets/ — Framework avatar image

## Constraints

- Requires PHP 8.2 and MariaDB services.
- Installation uses Composer to create a new Laravel project in `/app/laravel-{hostname}-{uuid}/`.
- Creates a symbolic link from the public directory to the install directory.

## Guidance

- The install script configures database credentials in the `.env` file automatically and runs `php artisan migrate`.
- File ownership is set to `nobody:nogroup` for proper web server access.
