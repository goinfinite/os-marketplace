Stack manifests directory containing complete development and production environment configurations. Stacks bundle multiple services (web server, database, runtime) into a unified deployable unit.

## Summary

- lamp/ — Linux, Apache, MySQL, PHP stack

## Constraints

- Each stack subdirectory MUST contain a manifest file (`.json`, `.yml`, or `.yaml`).
- Each stack subdirectory MUST contain an `assets/` directory with at minimum an avatar image.
- Manifest `type` property MUST be set to `stack`.

## Guidance

- Stack manifests SHOULD define all required services in the `services` property.
- Stacks typically do not require `installCmdSteps` as they rely on service provisioning.
